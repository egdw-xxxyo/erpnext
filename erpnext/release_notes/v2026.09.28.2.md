# Назви залежних завдань і доступ до огляду задачі

- **У «Залежних завданнях» видно назви задач.** Раніше таблиця показувала лише номери на кшталт TASK-2026-00192, тепер — назву задачі, посилання веде туди ж.
- **Огляд задачі відкривається без прав на заявки на матеріали.** Користувачі без доступу до Material Request бачили «Недостатньо дозволів для Material Request», і разом із помилкою зникав блок з оплатами дочірніх задач. Тепер блок заявок просто порожній, решта огляду на місці.
- **Кнопка «Створити → Material Request»** показується лише тим, хто може створювати заявки на матеріали.

# Технічна документація: дозавантаження файлів у проведену редакцію

- Редакція технічного документа: після проведення (зокрема вже чинна) можна додати Word-файл, файл PDF, скан із підписом чи додаткове вкладення, якщо цей слот ще порожній.
- Уже прикріплений файл проведеної редакції не можна замінити, очистити чи видалити: поле стає лише для читання, а сервер відхиляє спробу. Виправлений файл означає нову редакцію.
- Кожен дозавантажений файл записується в журнал документа з подією «Додано файл».

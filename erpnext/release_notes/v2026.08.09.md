# Звернення: діалог при зміні статусу та історія змін

- При зміні статусу Звернення (Lead) тепер відкривається діалог із обов'язковими полями для цього статусу (наприклад, «Причина закриття» для статусів «Не актуально» / «Втрачено», «Дата повернення» і «Причина відкладення» для «Відкладено», «Наступна дія» і «Дата наступної дії» для «Очікує відповіді»).
  - **Підтвердити** — значення записуються у форму.
  - **Скасувати** (або Esc / закриття вікна) — статус повертається до попереднього.
- Серверна перевірка обов'язкових полів залишилася без змін — вона гарантує коректність і для API та імпорту.
- **Потреба** (Customer Requirement) винесена на окрему вкладку разом із полем «Потреба клієнта».
- Увімкнено відстеження змін (**track_changes**) для Звернення — тепер у стрічці документа видно історію: хто, коли і з якою причиною змінив статус, причину закриття, причину відкладення тощо.

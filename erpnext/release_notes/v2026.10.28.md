# Допуски контролю якості котушок оптики в шаблоні

- Допуски перевірки котушки оптики (довжина ±1%, загасання, відбиття) тепер задаються формулами в шаблоні перевірки якості «Перевірка котушки оптики», а не в скрипті. У формулах доступні довжина котушки (`length_km`), атрибути варіанта товару (`attr["Тип волокна"]`), код товару та шаблон варіанта — тож для різних довжин і типів волокна допуски налаштовуються прямо в шаблоні.
- У шаблоні «Перевірка котушки оптики» з’явилась таблиця «Змінні»: допуски (загасання на км, загальне загасання для кожної довжини намотки, відбиття, допуск довжини %) редагуються як у таблиці допусків, без правки формул. Змінна може діяти для всіх товарів, для конкретного товару або для значення атрибута (наприклад, «Довжина намотки» = «25 км»).

# Очищення посилань на SOR-файли

- Щоденне очищення SOR-файлів тепер також прибирає «биті» посилання на файл у старих вимірюваннях OTDR, файли яких уже видалено.

# Швидкий доступ до чатів

- Плаваючу кнопку чату розділено на окремі кнопки-категорії (замість вкладок): WhatsApp, Чат співробітників і чат поточного документа стоять горизонтальним рядом у куті.
- Кожна кнопка має власний лічильник непрочитаних. Тепер видно непрочитані WhatsApp, навіть якщо ігноруєш чат співробітників, і навпаки.
- Кнопка «Обговорити цей документ» зʼявляється лише на відкритій картці запису й одразу відкриває єдиний чат цього запису (лічильник — тільки непрочитані цього запису).

## Модуль «Пристрої»: виправлення та довершення переносу

- Виправлено помилку «No module named 'erpnext.manufacturing.doctype.label_printer'» у діалозі друку етикеток та на інших екранах — усі виклики методів принтера, шаблонів етикеток і сканера тепер вказують на модуль «Пристрої».
- До модуля «Пристрої» перенесено також рефлектометр (OTDR, Налаштування OTDR), Скрипт робочого місця та сторінку «Черга друку».
- Роботу зі рефлектометром, скриптами робочого місця та чергою друку відкрито ролям «Device Manager» і «Device Operator» (доступ для ролей виробництва збережено).
- Старі шляхи API рефлектометра залишено сумісними, тому програми синхронізації OTDR (ПК і Android) працюють без оновлення.

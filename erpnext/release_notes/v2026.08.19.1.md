# Складська книга та зв'язки задач

## Складська книга: підсумки та напрямок переміщення

У звіті **Складська книга (Stock Ledger)** з'явилася кнопка **Підрахувати суми**. Вона рахує
підсумки по вже завантажених рядках і показує їх картками над таблицею: прихід (у к-сті),
розхід (Розхід у к-сті), чисту зміну кількості, зміну вартості та кількість рядків.

Суми навмисно рахуються тільки по натисканню кнопки — звіт часто відкривають за великий діапазон
дат, і автоматичний підрахунок сповільнював би його. Після зміни фільтрів або оновлення звіту
панель ховається, доки суми не перерахують знову.

Додано дві колонки: **Вихідний склад** і **Склад призначення**. Вони заповнюються з документа,
який створив рух: для переміщення видно обидва склади, для приходу — лише склад призначення,
для видатку — лише вихідний склад. Стара колонка **Склад** залишилася без змін.

## Задачі: коректні зв'язки при зміні Parent Task

Зняття або зміна **Батьківської задачі (Parent Task)** більше не лишає застарілого рядка в таблиці
**Залежить від (Task Depends On)** старої групи. Раніше такий рядок продовжував існувати, і система
відмовлялася видаляти чи скасовувати задачу з повідомленням «Неможливо видалити або скасувати,
оскільки Завдання … пов'язано з Завданням …», хоча зв'язку в дереві задач уже не було.

Тепер задача при кожному збереженні прибирає себе з таблиці «Залежить від» усіх групових задач,
яким вона більше не належить. Наявні застарілі зв'язки прибрано автоматично під час оновлення.
Видалення задачі блокується лише реальними залежностями.

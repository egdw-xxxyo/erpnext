# Військова частина у документах продажу

- Довідник **Військова частина (Military Unit)** перенесено з тестового сервера у код — тепер він створюється автоматично під час оновлення на всіх середовищах.
- Поле **Військова частина** додано до документів: **Можливість (Opportunity)**, **Пропозиція (Quotation)**, **Замовлення клієнта (Sales Order)**, **Звернення (Issue)**.
- Значення підставляється автоматично з контрагента документа (Клієнт / Потенційний клієнт / Запит), але його можна змінити вручну — ручний вибір зберігається під час наступних збережень.
- У картці **Потенційного клієнта (Prospect)** таблиці «Запити» та «Можливості» показують колонку **Військова частина** (лише для читання) — видно розбіжності з часткою самого Prospect.
- За військовою частиною можна фільтрувати списки Можливостей, Пропозицій, Замовлень клієнта та Звернень.
- Прибрано застаріле поле «Військова частина», створене через інтерфейс у Запиті (Lead); його значення перенесено до штатного поля.
- **Веб-сторінки (Web Page)**, зокрема «База знань» (`/kb`), більше не доступні неавторизованим відвідувачам — потрібен вхід у систему. Гість отримує сторінку «Не дозволено» з кнопкою входу та поверненням на потрібну адресу.

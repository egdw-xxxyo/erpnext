# Атрибути видно при скануванні

- **Глобальний сканер показує додаткові атрибути серійного номера.** Після сканування у картці
  зʼявляється блок *«Додаткові атрибути»* — наприклад, яка прошивка стоїть на цьому екземплярі.
- Блок показується лише тоді, коли для номера щось задано; поряд зі значенням виводиться
  примітка з рядка, якщо вона є.

# Реєстр документації ЄСКД

- Додано **Документ ЄСКД** (ESKD Document) — реєстр конструкторської документації: позначення, назва, тип документа, виріб, розділ, код організації (УКРП / ВРНК), ревізія, статус, вкладення та посилання на Специфікацію або Товар.
- Додано довідники **Тип документа ЄСКД** (Специфікація, ТУ, ІК, Паспорт, СК, ЭХ, ТК) та **Виріб ЄСКД** (з номером ТУ на кожен виріб).
- **Специфікація** (Specification) розширена полями каталогу: вид специфікації (борт / котушка / батарея / наземна станція), код організації, порядковий номер, виріб і таблиця параметрів (довжина намотування, діаметр шпулі, діаметр волокна, конфігурація батареї, тип камери).
- **Шаблон номера специфікації** (Specification Number Template) отримав компонент **Порядковий номер** (Ordinal) із заданою розрядністю — для позначень виду `УКРП.200121.002-11С`.
- Додано **Комбінація БпАК (ЄСКД)** (ESKD BpAK Combination) — перетин специфікації борту та специфікації НСУ з номером модифікації.
- Додано сторінку **Матриця БпАК** (`/app/eskd-bpak-matrix`): рядки — борти, колонки — наземні станції, клік по клітинці призначає (або звільняє) номер модифікації. Порожня клітинка = перетин, якому ще не призначено модифікацію.
- На робочому просторі **Склад** з'явилась картка **Документація ЄСКД** з посиланнями на всі довідники ЄСКД і на сторінку матриці.
- Додано імпортер книги `ЄСКД.xlsx` (`erpnext.manufacturing.eskd_import.run`): переносить зведений реєстр, таблицю ТУ, технологічні карти, каталоги котушок, батарей, наземних станцій і бортів. Імпорт ідемпотентний — повторний запуск застосовує лише зміни.

# Реєстр документації ЄСКД

- Додано **Документ ЄСКД** (ESKD Document) — реєстр конструкторської документації: позначення, назва, тип документа, виріб, розділ, код організації (УКРП / ВРНК), ревізія, статус, вкладення та посилання на Специфікацію або Товар.
- Додано довідники **Тип документа ЄСКД** (Специфікація, ТУ, ІК, Паспорт, СК, ЭХ, ТК) та **Виріб ЄСКД** (з номером ТУ на кожен виріб).
- **Специфікація** (Specification) розширена полями каталогу: вид специфікації (борт / котушка / батарея / наземна станція), код організації, порядковий номер, виріб і таблиця параметрів (довжина намотування, діаметр шпулі, діаметр волокна, конфігурація батареї, тип камери).
- **Шаблон номера специфікації** (Specification Number Template) отримав компонент **Порядковий номер** (Ordinal) із заданою розрядністю — для позначень виду `УКРП.200121.002-11С`.
- **Специфікація** тепер може містити **складові специфікації** (Specification Component) — кожна у своїй ролі: борт складається з котушки та батареї, БпАК — з борту та НСУ. Ролі ведуться в довіднику **Роль компонента специфікації**.
- Додано шаблони специфікацій (борт, котушка, батарея, НСУ, БпАК) з **Шаблонами номера специфікації**: код формується з атрибутів (організація, клас дрона, типорозмір рами, тип камери) та порядкових номерів складових, а не вводиться вручну.
- Назва варіанта специфікації **генерується автоматично** за шаблоном (поле «Шаблон назви варіанта»): у ній збираються обрані атрибути, порядковий номер (`{ORDINAL}`) і назви складових за роллю (`{Котушка}`, `{Батарея}`, `{Борт}`, `{НСУ}`). Для варіантів назва й позначення лише для читання.
- Батарея описується наявними атрибутами **Конфігурація S** і **Конфігурація P** (6S + 3P), котушка — новим атрибутом **Тип котушки**, НСУ — атрибутами **Тип сигналу НСУ** і **Виконання НСУ**. Абревіатура значення дорівнює порядковому номеру в таблиці ЄСКД.
- Варіант успадковує **вид специфікації** від шаблону.
- У формі **Специфікації** прапорець «Має варіанти» перенесено вгору, поле «Порядковий номер» ховається для шаблонів, а в списку специфікацій шаблони позначені синім індикатором «Шаблон».
- До атрибута **Типорозмір рами** додано значення «Інша рама» (код `99`) — для блоку «Укропчик 10 FO (іньша рама)» з книги ЄСКД.
- БпАК — це специфікація виду **БпАК** зі складовими «Борт» і «НСУ» та номером модифікації.
- Додано сторінку **Матриця БпАК** (`/app/eskd-bpak-matrix`): рядки — специфікації бортів, колонки — специфікації НСУ, клік по клітинці створює (або видаляє) БпАК для цього перетину.
- На робочому просторі **Склад** з'явилась картка **Документація ЄСКД** з посиланнями на всі довідники ЄСКД і на сторінку матриці.
- Додано імпортер книги `ЄСКД.xlsx` (`erpnext.manufacturing.eskd_import.run`): переносить зведений реєстр, таблицю ТУ, технологічні карти, каталоги котушок, батарей, наземних станцій і бортів. Імпорт ідемпотентний — повторний запуск застосовує лише зміни.

# Голосові повідомлення у всіх чатах

- Додано кнопку 🎤 для запису голосового повідомлення з мікрофона в усіх чатах: **Центр WhatsApp**, **Чат співробітників** та плаваюче вікно чату (fab).
- Під час запису показується панель із таймером та кнопками **Надіслати**/**Скасувати**.
- Голосові повідомлення відтворюються прямо в чаті (аудіоплеєр), зокрема у секретних чатах — там аудіо шифрується у браузері, як і інші вкладення.
- Для WhatsApp: якщо браузер (Chrome) може записати лише `webm`, сервер автоматично перекодовує аудіо у `ogg/opus` через ffmpeg, бо Meta не приймає `webm`. Firefox/Safari записують у сумісному форматі одразу.
- До образу додано `ffmpeg` для серверного перекодування.

## Виправлення

- Аудіоплеєр у чаті більше не «стискається» до вузької смужки — задано коректну ширину.
- Реакції (емодзі) під повідомленнями з зображеннями/медіа більше не перекривають наступне повідомлення — для повідомлень із реакціями зарезервовано місце.

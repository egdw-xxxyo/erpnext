# HTTPS для пристроїв у VPN

- Сайт можна відкривати через HTTPS за доменним іменем: сертифікат Let's Encrypt видається й поновлюється автоматично через перевірку DNS у Cloudflare, тож сервер не потрібно відкривати в інтернет. Вмикається файлом `.tls.env` на сервері (зразок — `.tls.env.example`).
- Коли HTTPS увімкнено, QR-код підключення та конфігураційні штрихкоди сканерів містять адресу `https://…`; старий доступ `http://<IP>:8080` продовжує працювати.
- Сканер: кнопка «Сканувати код» у формі сканера — камера браузера зчитує штрихкод або QR-код і надсилає його сканеру так само, як сам пристрій; відповідь сканера видно одразу, код можна ввести й вручну.
- Мобільний застосунок 0.8.0: сканування камерою на екрані сканера. Одне фото — усі штрихкоди та QR-коди на ньому розпізнаються й підсвічуються; їх можна надсилати по одному дотиком або всі разом по черзі. Якщо код один, він надсилається автоматично; якщо сканер відповів помилкою, черга зупиняється, решта кодів лишається доступною.

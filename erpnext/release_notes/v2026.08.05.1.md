# Українська термінологія Запиту (Lead) в інтерфейсі та звітах

- Терміни Запиту (Lead) тепер справді відображаються в інтерфейсі: переклади дублювалися у `locale/uk.po`, який має вищий пріоритет за `translations/uk.csv`, тому попередні правки лише в CSV не доходили до UI.
- Виправлено машинні переклади: «Вести» → **Запит**, «Ліди» → **Запити**, «Власник Lead-а» → **Відповідальний менеджер**, «Lead Source» → **Канал залучення**, «Тип Lead-а» → **Тип Запиту**, «Деталі Lead-а» → **Деталі Запиту**.
- Звіт «Свинець Власник Ефективність» перейменовано на **Ефективність відповідального менеджера**; його колонки: **Кількість Можливостей**, **Кількість Пропозицій**, **Кількість Замовлень**, **Можливості/Запити %**, **Пропозиції/Запити %**, **Замовлення/Пропозиції %** (раніше — «Opp граф», «ОПП / Свинець%», «Quot / Свинець%»).
- Приведено до єдиної термінології решту рядків: «Додати Запит до потенційного клієнта», «Видалити Запити та адреси», «Мінімальний вік Запиту (днів)», «Адреса Клієнта / Запиту», «Новий Запит (за останній 1 місяць)».

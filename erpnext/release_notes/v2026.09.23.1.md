# Оновлення репозиторію більше не застрягає

- **`./updateRepo` знову доходить до кінця на сервері.** Скрипт переводив підмодуль `frappe` на вершину його гілки (`--remote`), а потім додавав цю розбіжність в індекс (`git add frappe`). На сервері цей індекс ніхто не комітить, тож наступний запуск падав ще до `git pull`: «Your local changes to the following files would be overwritten by merge: frappe». Тепер розгортання бере саме той коміт `frappe`, який зафіксовано в репозиторії (і з яким тестувався коміт erpnext), а залишений попереднім запуском покажчик скидається перед `git pull`. Зсунути покажчик уперед і далі можна — прапорцем `--bump-submodules` на машині розробника, з подальшим комітом.

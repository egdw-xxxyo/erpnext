# Подорожній лист (Vehicle Trip)

## Огляд (Overview)

Подорожній лист (Vehicle Trip) — це документ для обліку поїздок службовим транспортом. Має двоетапний процес:

1. **Початок поїздки** — працівник обирає транспорт, пункт призначення та записує показник одометра
2. **Завершення поїздки** — працівник записує кінцевий одометр, витрату пального та нотатки

## DocTypes

| DocType | Шлях (Path) | Призначення |
|---|---|---|
| Vehicle Trip | `erpnext/setup/doctype/vehicle_trip/` | Подорожній лист |
| Vehicle Destination | `erpnext/setup/doctype/vehicle_destination/` | Довідник пунктів призначення |
| Vehicle | `erpnext/setup/doctype/vehicle/` | Транспортний засіб (стандартний ERPNext) |

## Потік роботи (Workflow)

### Крок 1: Початок поїздки (Start Trip)

1. Відкрити **Vehicle Trip** → **+ New**
2. Заповнити:
   - **Працівник (Employee)** — хто їде
   - **Транспорт (Vehicle)** — автоматично підтягує останній одометр, марку, тип пального
   - **Показник одометра на початку (Odometer Start)** — заповнюється автоматично з останнього запису
   - **Пункт призначення (Destination)** — обрати з довідника Vehicle Destination
   - **Мета поїздки (Purpose)** — необов'язково
3. Натиснути **Зберегти (Save)**
4. Статус: **В дорозі (En Route)** — синій індикатор

> **Валідація**: неможливо створити нову поїздку на транспорт, який вже має статус "В дорозі" (En Route).

### Крок 2: Завершення поїздки (Complete Trip)

1. Відкрити існуючий подорожній лист зі статусом "В дорозі"
2. Натиснути кнопку **Complete Trip** (прокручує до секції завершення)
3. Заповнити:
   - **Показник одометра в кінці (Odometer End)** — відстань розраховується автоматично
   - **Кількість пального (Fuel Quantity)** — необов'язково
   - **Нотатки (Notes)** — необов'язково
4. Натиснути **Зберегти (Save)** — статус змінюється на **Завершено (Completed)** — зелений індикатор
5. Натиснути **Підтвердити (Submit)** — оновлює останній показник одометра на транспорті

### Скасування (Cancel)

При скасуванні подорожнього листа одометр транспорту повертається до значення з попередньої поїздки.

## Статуси (Statuses)

| Статус | Колір | Умова |
|---|---|---|
| В дорозі (En Route) | Синій | Збережено без Odometer End |
| Завершено (Completed) | Зелений | Заповнено Odometer End |
| Скасовано (Cancelled) | Червоний | Документ скасовано |

## Пункти призначення (Vehicle Destination)

Довідник часто використовуваних пунктів призначення. Має **Quick Entry** — можна створити новий запис прямо з поля Destination у подорожньому листі.

| Поле | Тип | Опис |
|---|---|---|
| Destination Name | Data | Назва (є ідентифікатором запису) |
| Address | Data | Адреса (необов'язково) |

**Шлях**: Setup → Vehicle Destination

## Права доступу (Permissions)

| Роль | Vehicle Trip | Vehicle Destination |
|---|---|---|
| Fleet Manager | Повний доступ (Full access) | Повний доступ |
| Delivery Manager | Створення, читання, підтвердження | Створення, читання, редагування |
| Delivery User | Створення, читання, редагування | Створення, читання |

## Зв'язок з Vehicle

Транспорт (Vehicle) має Dashboard-зв'язок з Vehicle Trip через поле `vehicle`. При відкритті картки транспорту в бічній панелі відображаються пов'язані подорожні листи.

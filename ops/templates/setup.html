Passwordless sudo

Some actions need root on the host (reading /var/lib/docker, installing a package, trimming the journal). The dashboard never asks for or stores a sudo password: it calls sudo -n, which fails immediately instead of hanging when the host does not allow the command. So the host has to allow exactly those commands, once, by an admin who has sudo. The dashboard cannot do this itself — writing the file needs root.
